# 💼 Data Science Salary Predictor

A machine learning web app that predicts data science salaries based on experience level, company size, and remote work ratio.

## 🔗 Live Demo
👉 [Click here to try the app](https://howrang23-salary-predictor.streamlit.app)

## 📌 About the Project
This project uses a Random Forest machine learning model trained on real-world data science job salaries. Users can input their details and get an estimated annual salary instantly.

## 🛠️ Tools & Technologies
- **Python** — programming language
- **Pandas & NumPy** — data cleaning and processing
- **Scikit-learn** — machine learning model
- **Streamlit** — web app framework
- **Matplotlib & Seaborn** — data visualization

## 📊 Dataset
- Source: [Data Science Job Salaries - Kaggle](https://kaggle.com)
- Contains real-world salary data with experience level, job title, company size, and remote ratio

## 🚀 How to Run Locally
1. Clone the repository
   git clone https://github.com/howrang23/salary-predictor.git
2. Install dependencies
   pip install -r requirements.txt
3. Train the model
   python model.py
4. Run the app
   streamlit run app.py

## 📁 Project Structure
- model.py — trains and saves the ML model
- app.py — Streamlit web app
- requirements.txt — list of dependencies
- ds_salaries.csv — dataset
